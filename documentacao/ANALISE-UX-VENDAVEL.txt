MELHORIAS ADICIONADAS NA VERSÃO DE COMPRA E ENTREGA
----------------------------------------------------
1. Navbar mais leve para visitante:
   - Login e Registar aparecem em formato vertical compacto.
   - Carrinho aparece apenas como ícone com contador.
   - Ao passar o rato sobre o carrinho, aparece a palavra "Carrinho" com animação suave.

2. Carrinho com atualização automática:
   - Ao alterar a quantidade, o subtotal e o total atualizam automaticamente.
   - O utilizador não precisa clicar em "Atualizar Carrinho".
   - Existe fallback com botão dentro de <noscript> caso o JavaScript esteja desativado.

3. Novo fluxo de entrega:
   - Pendente: encomenda criada e aguardando preparação.
   - A caminho: encomenda enviada para entrega.
   - Entregue: encomenda finalizada.

4. Confirmação pelo cliente:
   - Quando a encomenda está "A caminho", o cliente pode confirmar a receção na página de detalhes da encomenda.

5. Guia de entrega para transportador:
   - O admin pode abrir uma guia de entrega imprimível.
   - A guia pode ser impressa ou guardada em PDF pelo navegador.
   - Inclui dados do cliente, morada, produtos, total, observações e espaço para assinaturas.

MELHORIA: GUIA DE ENTREGA E ENVIO AO MOTORISTA
----------------------------------------------
A guia de entrega foi melhorada para uso real pelo administrador:

1. O link bruto do Google Maps foi removido da versão impressa/PDF.
2. Foi criado um botão visual para abrir a localização no Google Maps apenas no ecrã.
3. Foi criada a ação admin_send_driver_whatsapp.php.
4. O administrador pode inserir o número do motorista com prefixo +351.
5. O sistema prepara uma mensagem de WhatsApp com:
   - número da encomenda;
   - cliente;
   - morada;
   - link do Google Maps;
   - produtos e quantidades;
   - total;
   - link da guia de entrega.
6. Para envio automático de PDF anexado seria necessária uma API oficial do WhatsApp.



ATUALIZAÇÃO AJAX NO ADMIN

Para melhorar a experiência do administrador, foram aplicadas atualizações sem recarregar a página nas seguintes áreas:

1. Gerir Encomendas:
   - Ao alterar o estado da encomenda e clicar em Guardar, o sistema usa AJAX para atualizar a base de dados sem reiniciar a página.
   - O admin permanece no mesmo ponto da tabela.
   - Aparece feedback visual de sucesso ou erro.

2. Gerir Utilizadores:
   - Ao alterar a função user/admin e clicar em Guardar, a alteração é feita por AJAX.
   - A remoção de utilizadores também remove a linha da tabela sem recarregar.

3. Gerir Produtos:
   - A remoção de produtos foi melhorada com AJAX, removendo a linha da tabela sem reiniciar a página.

As funcionalidades continuam com fallback normal em PHP caso o JavaScript esteja desativado.
