- index.html redireciona para index.php

[OK] Versão PHP principal:
- index.php
- sobre.php
- albuns.php
- tour.php
- contactos.php
- loja.php

[OK] Sistema de utilizadores:
- register.php cria utilizador normal com role user
- login.php valida username/email e senha
- logout.php termina a sessão
- profile.php é página protegida
- password_hash usado no registo
- password_verify usado no login
- sessões PHP usadas para autenticação

[OK] Loja online:
- Produtos vêm da base de dados MySQL
- Produtos têm imagem, descrição, preço, stock e categoria
- Loja tem filtro por categoria
- Loja tem busca por nome de produto

[OK] Carrinho:
- Carrinho guardado em sessão PHP
- cart.php mostra produtos, preço, quantidade, subtotal e total
- É possível alterar quantidade
- É possível remover produto

[OK] Checkout:
- checkout.php exige login
- Pedido é gravado em orders
- Produtos do pedido são gravados em order_items
- Stock é atualizado após a compra

[OK] Área de administração:
- admin.php só abre para role admin
- admin_products.php lista, edita e remove produtos
- admin_product_form.php adiciona/edita produtos
- Upload de imagem do produto por ficheiro
- Categorias por dropdown
- Possibilidade de criar nova categoria no próprio formulário
- admin_users.php gere utilizadores e funções
- admin_orders.php gere encomendas e estados
- admin_order_details.php mostra detalhes completos de cada encomenda

[OK] Melhorias extras:
- Formulários destacam campos obrigatórios vazios com contorno vermelho
- O aviso padrão de preenchimento obrigatório do navegador continua ativo
- Campos do formulário de contacto têm atributo name
- Utilizador normal consegue ver detalhes das próprias encomendas
- Admin consegue ver detalhes completos das encomendas

[OK] Base de dados:
- database/seu_jorge_store.sql incluído
- users

- categories

- order_items
